# Security Policy

All customer data is encrypted at rest with AES-256 and in transit with TLS 1.3. Encryption keys are rotated every 90 days and stored in a hardware security module.

Employees must use hardware security keys for multi-factor authentication. SMS-based one-time codes are not permitted for any internal system.

Production access follows the principle of least privilege. Engineers request time-boxed access through the access portal, and every session is recorded and reviewed weekly by the security team.

Security vulnerabilities can be reported to the responsible disclosure programme. Valid critical findings are rewarded with bounties of up to 5,000 USD, and we aim to acknowledge every report within 2 business days.

Penetration tests are performed by an independent firm twice a year, and a summary report is available to enterprise customers under NDA.
