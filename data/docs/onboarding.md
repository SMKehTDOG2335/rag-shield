# Engineering Onboarding

New engineers receive their laptop and hardware security key on day one. Accounts for email, chat and the code repository are provisioned by IT before the start date.

During the first week every new hire is paired with an onboarding buddy from their team, who helps them set up the development environment and ship a small first change.

All engineers must complete the secure coding training within their first 30 days. Production access is only granted after the training is complete and the manager approves the request.

The on-call rotation starts after 3 months. New on-call engineers shadow an experienced engineer for two full rotations before carrying the pager alone.
